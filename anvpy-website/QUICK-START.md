# 🚀 Quick Start Guide - AnvPy Website

## Viewing the Website

### Option 1: Direct File Opening
1. Navigate to `/app/anvpy-website/`
2. Open `index.html` in any modern web browser
3. Done! The website is fully functional

### Option 2: Local Server (Recommended)

**Using Python:**
```bash
cd /app/anvpy-website
python3 -m http.server 8000
```
Then open: `http://localhost:8000`

**Using Node.js:**
```bash
cd /app/anvpy-website
npx serve
```

**Using PHP:**
```bash
cd /app/anvpy-website
php -S localhost:8000
```
