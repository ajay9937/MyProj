# AnvPy Ecosystem Platform Website

A complete, production-grade, professional, fully responsive, and highly animated technical website for the AnvPy Ecosystem Platform.

## 🚀 Overview

This is a world-class developer platform website built with pure HTML, CSS, and Vanilla JavaScript - NO frameworks used.

## 📁 Structure

```
anvpy-website/
├── index.html          # Home page
├── download.html       # Download page
├── ecosystem.html      # Ecosystem overview
├── features.html       # Features showcase
├── docs.html          # Documentation
├── showcase.html      # App showcase
├── community.html     # Community page
├── about.html         # About page
├── contact.html       # Contact page
├── css/
│   └── style.css      # Complete styling system
└── js/
    └── main.js        # All interactive functionality
```

## 🚀 How to View

   ```bash

   # or
   npx serve
   ```

## 📦 No Dependencies

This website is built with zero external dependencies or frameworks. Everything is vanilla HTML, CSS, and JavaScript for maximum performance and simplicity.

## ⚡ Performance Optimized

- Lightweight (no frameworks)
- Hardware-accelerated animations
- Efficient CSS animations
- Intersection Observer for lazy loading
- Debounced scroll events
- RequestAnimationFrame for smooth performance
