Getting Started

Welcome to AnvPy! This guide will help you set up your development environment and create your first Python application for Android.

Prerequisites

  • Android device with Android 7.0 or higher
  • Basic knowledge of Python programming
  • 500MB of free storage space

Installation

Installing AnvPyX on Android

1

Download APK

Download the latest AnvPyX APK from the download page.

2

Enable Installation

Go to Settings > Security and enable "Install from Unknown Sources" for your browser or file manager.

3

Install APK

Open the downloaded APK file and follow the installation prompts.

4

Launch AnvPyX

Open the AnvPyX app from your app drawer. The first launch will initialize the Python environment.

Installing AnvPy CLI on Desktop

Terminal
# Windows
curl -o anvpy-cli-setup.exe https://anvpy.dev/downloads/cli/windows
anvpy-cli-setup.exe

# Linux
curl -o anvpy-cli.sh https://anvpy.dev/downloads/cli/linux
sudo bash anvpy-cli.sh

# macOS
curl -o anvpy-cli.pkg https://anvpy.dev/downloads/cli/macos
sudo installer -pkg anvpy-cli.pkg -target /

Create Your First App

Using Alloy GUI Framework

Let's create a simple "Hello World" application using the Alloy framework:

hello_world.py
from alloy import App, Button, TextView, Layout

class HelloApp(App):
    def __init__(self):
        super().__init__("Hello World")
        
    def on_create(self):
        # Create layout
        layout = Layout.vertical()
        
        # Add text view
        text = TextView("Welcome to AnvPy!")
        text.set_text_size(24)
        layout.add(text)
        
        # Add button
        button = Button("Click Me")
        button.on_click(self.button_clicked)
        layout.add(button)
        
        self.set_content_view(layout)
    
    def button_clicked(self):
        self.show_toast("Hello from AnvPy!")

if __name__ == "__main__":
    app = HelloApp()
    app.run()

Running Your App

1

Open AnvPyX and create a new project

2

Copy the code above into your main.py file

3

Tap the "Run" button to execute your application

Build APK

Convert your Python application into an installable APK file using AnvPack:

Terminal
# Initialize project for packaging
anvpack init myapp

# Configure app details
anvpack config --name "My App" --version "1.0.0"
anvpack config --icon "icon.png" --package "com.myapp"

# Build APK
anvpack build

# Output: myapp-1.0.0.apk

Important Notes

  • Ensure all dependencies are included in your project
  • Test your app thoroughly before building
  • Use appropriate permissions in the manifest

Deploy Your App

Testing on Device

Install and test your APK directly on your Android device:

Terminal
# Install APK to connected device
adb install myapp-1.0.0.apk

# Or use AnvPy CLI
anvpy deploy myapp-1.0.0.apk
