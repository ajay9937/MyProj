AnvPyX

Version 3.0.0 - Next Generation

AnvPyX is the latest generation of the AnvPy ecosystem, providing a complete Python runtime, native GUI framework (Alloy), AI support (OpenCV, TensorFlow, PyTorch, MediaPipe), game engines (Pygame, Luna 2D, Nova 3D), and APK packaging directly on Android devices.

✓ Full Python 3.11 Runtime
✓ Native Alloy GUI Framework
✓ AI/ML Libraries Built-in
✓ Luna & Nova Game Engines
