Complete Ecosystem

A comprehensive suite of tools for Python development on Android

🐍

Python Runtime

Full native Python runtime optimized for Android ARM processors. Supports the complete Python standard library with offline execution capabilities. Built from source specifically for mobile ARM64 architecture, ensuring maximum performance and compatibility.

Python 3.11 ARM64 Optimized Offline Support Full Stdlib
📦

AnvBuild

Native package management and build system designed specifically for mobile environments. Install and manage Python packages with optimized builds for Android. Simple command-line interface for dependency management.

$ anvbuild install opencv
$ anvbuild install tensorflow
$ anvbuild update
Package Manager Mobile Optimized Fast Builds
🤖

Comprehensive AI and machine learning capabilities with optimized builds of industry-standard libraries. Run computer vision, neural networks, and AI applications directly on Android devices.

OpenCV

TensorFlow

PyTorch

MediaPipe

ML solutions for mobile

Alloy GUI

Native Android UI framework for building real Android applications using pure Python. Create beautiful, responsive interfaces with native Android components and Material Design support.

from alloy import App, Button, Layout

app = App("My App")
layout = Layout.vertical()
button = Button("Click Me")
layout.add(button)
app.run()
Native UI Material Design Python API
🎭

Kivy Support

Full support for the Kivy cross-platform GUI framework. Build applications that run on Android, iOS, Windows, Linux, and macOS from a single codebase.

Cross-Platform Touch Support Custom Widgets
🎮

Pygame

Popular 2D game development framework optimized for mobile. Create games with sprite management, collision detection, sound, and input handling.

2D Graphics Sound Engine Physics
🌙

Luna Engine

Advanced 2D game engine specifically optimized for mobile devices. Features include particle systems, animation framework, tilemap support, and advanced rendering capabilities.

Particle Systems Tilemaps Animations Mobile Optimized
⭐

Nova Engine

Powerful 3D game engine with OpenGL rendering support. Build immersive 3D games with scene management, camera systems, lighting, and physics simulation.

3D Rendering OpenGL Physics Engine Scene Manager
💻

Code Editor

Built-in professional code editor with syntax highlighting for Python, multiple color themes, auto-indentation, and code completion. Write code efficiently directly on your device.

Syntax Highlighting Auto-Complete Multiple Themes
📱

AnvPack

Convert your Python applications into installable APK files. Package your apps with custom icons, permissions, and configurations for distribution.

$ anvpack build myapp
$ anvpack sign myapp.apk
$ anvpack release
APK Builder Custom Icons Permissions
🏪

AnvStore

App publishing and distribution platform for AnvPy applications. Share your creations with the community, discover new apps, and manage updates.

App Publishing Distribution Updates Community
⚡

AnvPy CLI

Desktop development tool for Windows, Linux, and macOS. Create projects, manage dependencies, build APKs, and deploy applications from your PC to Android devices.

$ anvpy init myproject
$ anvpy add package opencv
$ anvpy build apk
$ anvpy deploy
Cross-Platform CLI Project Manager Build Tools
